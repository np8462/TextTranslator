# TextTranslator — Store Listing Draft

This file contains proposed bilingual listing copy for the browser extension stores. Review it against the final tested build before submitting.

## English

**Name:** TextTranslator – Online & Offline Dictionary

**Short description:** Translate selected or hovered words with pair-specific offline dictionaries and optional online lookup.

**Detailed description:**

TextTranslator helps you understand words as you browse.

- Hover over a word or select a word or phrase to see its meaning.
- Choose the source and target languages independently.
- Switch between online translation and local offline dictionaries.
- Keep separate dictionaries for each language pair.
- Add your own words, import JSON dictionaries, check dictionary files, and export one dictionary or a complete ZIP backup.
- Adjust how long the meaning tooltip stays visible.
- Use offline dictionaries without sending lookup text to an online translation provider.

TextTranslator is free to use. It contains no advertisements, analytics, or user-tracking features. Online translation requires an internet connection and sends the submitted word or selected phrase, plus the language pair, to the selected translation provider. See PRIVACY.md for details.

**Suggested category:** Productivity / Education

## فارسی

**نام:** TextTranslator – دیکشنری آنلاین و آفلاین

**توضیح کوتاه:** معنی واژه‌ها و عبارت‌های انتخاب‌شده یا زیر نشانگر ماوس را با دیکشنری آنلاین و آفلاین ببینید.

**توضیحات کامل:**

با TextTranslator هنگام مرور صفحات وب معنی واژه‌ها را سریع‌تر پیدا کنید.

- با حرکت ماوس روی یک واژه یا انتخاب واژه و عبارت، معنی آن را ببینید.
- زبان مبدأ و مقصد را مستقل انتخاب کنید.
- بین ترجمهٔ آنلاین و دیکشنری آفلاین محلی جابه‌جا شوید.
- برای هر جفت‌زبان دیکشنری جداگانه داشته باشید.
- واژه‌های دلخواه را اضافه کنید، فایل‌های JSON را وارد و بررسی کنید و از یک یا همهٔ دیکشنری‌ها خروجی بگیرید.
- مدت نمایش پنجرهٔ معنی را تنظیم کنید.
- در حالت آفلاین بدون ارسال متن برای سرویس ترجمهٔ اینترنتی از دیکشنری استفاده کنید.

استفاده از TextTranslator رایگان است. افزونه تبلیغات، ابزار تحلیل رفتار یا قابلیت ردیابی کاربران ندارد. ترجمهٔ آنلاین به اینترنت نیاز دارد و واژه یا عبارت ارسالی به همراه جفت‌زبان برای سرویس ترجمهٔ انتخاب‌شده فرستاده می‌شود. جزئیات در PRIVACY.md آمده است.

**دسته‌بندی پیشنهادی:** بهره‌وری / آموزش
