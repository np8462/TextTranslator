جست‌وجوی معنی

روش دلخواه را انتخاب کن؛ برای کلمهٔ جدید ابتدا آنلاین جست‌وجو کن.

تنظیم دیکشنری آنلاین

آدرس پیش‌فرض MyMemory انگلیسی به فارسی است. سرویس سفارشی باید JSON با فیلد meaning یا responseData.translatedText برگرداند.

راهنمای استفاده

  1. جست‌وجوی آفلاین فقط از واژه‌های ذخیره‌شده استفاده می‌کند.
  2. جست‌وجوی آنلاین معنی را از سرویس انتخاب‌شده می‌گیرد.
  3. پس از پیدا شدن معنی آنلاین، دکمهٔ ＋ را بزن تا برای استفادهٔ آفلاین ذخیره شود.
