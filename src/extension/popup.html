تنظیم زبان و حالت

هر جفت‌زبان دیکشنری مستقل دارد؛ برای زبان‌های اصلی به فارسی و فارسی به آن زبان، واژه‌های اولیه هم اضافه شده‌اند.

مدت را به ثانیه دستی وارد کن؛ از ۱ تا ۶۰ ثانیه. مقدار پیش‌فرض ۲ ثانیه است.

حالت انتخاب‌شده هم در این پنجره و هم هنگام هایلایت کلمات استفاده می‌شود.

یک واژه وارد کن و «پیدا کردن معنی» را بزن.

ذخیره فقط پس از دریافت معنی آنلاین فعال می‌شود. واژه‌ها در حافظهٔ محلی همین مرورگر Chrome و جداگانه برای هر جفت‌زبان نگهداری می‌شوند؛ داخل فایل‌های GitHub ذخیره نمی‌شوند.

مدیریت دیکشنری

برای Import می‌توانی یک یا چند فایل JSON را هم‌زمان انتخاب کنی. جفت‌زبان از فرادادهٔ فایل یا نامی مانند en-fa.json تشخیص داده می‌شود؛ اگر مشخص نباشد، آن فایل وارد نمی‌شود تا واژه‌ها در دیکشنری اشتباه قرار نگیرند.

هنوز عملیاتی انجام نشده است.

اگر واژه‌ای در فایل واردشده با واژهٔ موجود هم‌نام باشد، معنی فایل واردشده جایگزین معنی قبلی همان دیکشنری می‌شود. انتخاب یک جفت‌زبان، فایل JSON همان دیکشنری را می‌سازد؛ انتخاب «همهٔ دیکشنری‌ها» یک فایل ZIP شامل JSON جداگانه برای هر جفت‌زبان می‌سازد. محل ذخیره را تنظیمات دانلود Chrome تعیین می‌کند. به‌روزرسانی آنلاین، همهٔ جفت‌زبان‌هایی را بررسی می‌کند که در فهرست مخزن بسته دارند.

تنظیم دیکشنری آنلاین

آدرس پیش‌فرض از رابط عمومی و غیررسمی ترجمهٔ گوگل استفاده می‌کند؛ تضمین پایداری یا پشتیبانی رسمی ندارد. API رسمی Google Cloud Translation نیازمند تنظیمات و احتمالاً هزینه است.

راهنمای استفاده

  1. زبان مبدأ و مقصد را انتخاب و «اعمال زبان‌ها» را بزن.
  2. حالت آنلاین یا آفلاین را انتخاب کن؛ همین حالت برای کلمات هایلایت‌شده نیز استفاده می‌شود.
  3. در حالت آنلاین، معنی از سرویس آنلاین گرفته می‌شود؛ اگر واژه در دیکشنری آفلاین همان جفت‌زبان نباشد، پس از دریافت موفق به‌طور خودکار ذخیره می‌شود و پیام سبز کوتاهی نمایش داده می‌شود.
  4. در حالت آفلاین، فقط دیکشنری همان جفت‌زبان بررسی می‌شود؛ اگر واژه موجود نباشد، درخواست آنلاین انجام نمی‌شود.
